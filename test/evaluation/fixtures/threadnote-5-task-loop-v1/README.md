# Threadnote 5 task-loop evaluation fixture

This offline fixture freezes the release gates for the local-first 5.0 task loop. Evaluation runners may record
version-specific observations separately, but must not weaken these contracts or require network access. The six cases
cover activation, closeout usefulness, stale citation handling, contradiction triage, projection drift, and bounded
Context Brief/Knowledge Delta output.

The fixture contains only thresholds and closed outcome labels. It deliberately contains no repository name, path,
query, source fragment, memory body, user identifier, credential, or raw log.
